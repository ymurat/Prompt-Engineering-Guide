# Academic Prompt Toolkit for Software Engineering, AI & VR

A set of Turkish-English prompt templates for research, lesson preparation, and project evaluation. Choose the Turkish or English version of a template, replace its bracketed fields, and provide the relevant context or materials.

## Templates

- [Literature synthesis](literature-synthesis.md): synthesize only the sources you provide and distinguish shared findings from disagreements.
- [Software engineering research design](software-engineering-research-design.md): develop research questions, a method, measures, and an analysis plan.
- [Lesson and activity design](lesson-and-activity-design.md): prepare outcomes, an explanation, a hands-on activity, and a rubric.
- [AI, VR, and serious-game project evaluation](ai-vr-serious-game-evaluation.md): evaluate a project using the supplied evidence and prioritize improvements.

## How to use the templates

1. Choose one template and one language version; submit that prompt in your model or tool.
2. Replace every bracketed field (for example, `[topic]`, `[duration]`, or `[learner level]`) with specific details. For the literature synthesis prompt, state your research question and provide the source texts, excerpts, or files you want analyzed.
3. For project evaluation, include the materials you want assessed—such as a project description, code, screenshots, or a demo—and make clear which parts are available for inspection.
4. Review the result against the sources or project materials. These prompts request evidence-aware answers, but they do not guarantee factual accuracy or replace expert review.

If a field is not relevant, remove it or explain why it is unspecified instead of leaving an ambiguous placeholder. The Turkish and English versions are alternatives; request a bilingual response separately if you want the answer in both languages.
